# Setup

1. Create a public repo named exactly **gronseth** (`github.com/gronseth/gronseth`). GitHub shows its README on your profile.
2. Copy `README.md` and the `assets/` folder into it, then commit and push.
3. Check the Bluesky and Mastodon URLs in README.md.

To change the text, edit `GitHub README Assets.dc.html` and re-export the PNGs. GitHub strips CSS and custom fonts, so the styled parts have to be images. The alt text keeps them readable for screen readers.
